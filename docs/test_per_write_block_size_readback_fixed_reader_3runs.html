32 B 普通 write，第一层 block 从 1 KiB 到 1 GiB；writer 池上限 2 GiB。 reader 单块 = min(writer block × 10, 2 GiB)，reader 池总量上限始终 2 GiB；实际容量按完整块数向下取整。 每轮上限按 reader 实际容量的 80% 计算。每项 1,000 万条、预热 5 万条、回调循环 0、各指标 3 次算术平均。

本次观察

每条发布时，原版本次均值最高为 2 KiB、158.238 M条/s；读回版为 2 MiB、382.675 M条/s。 在同一个 2 MiB 参数点，吞吐从 23.801 提升至 382.675 M条/s，p50 从 42.819 降至 2.417 ns。
