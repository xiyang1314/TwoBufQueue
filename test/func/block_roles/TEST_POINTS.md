# WriterBlock / ReaderBlock 拆分测试点

1. 接口隔离：BasicBlock 不公开业务分配接口；WriterBlock 只公开无参读取切片接口；ReaderBlock 只公开普通分配接口。
2. 公共所有权：两类块使用相同基础块和切片分配器，切片可放入同一个 DataBatch；不同池的句柄正确归属和释放。
3. ReaderBlock：空块即可分配；对齐、容量、槽位、分配失败及三种并发策略不改变已有数据；停止分配与切片释放共同决定回收。
4. WriterBlock：未发布字节不能被读取；增量发布、空增量、写入结束、离开 Writer、未读尾部、异步持有分别保护块生命周期。
5. 回收隔离：先登记切片再发布分配游标；池不得仅按基础类条件提前回收 WriterBlock。
6. 内存缩减和复用：恢复后游标清零、发布指针重新绑定；旧代切片不能修改新代计数。
7. 集成：直接回调和 BigMemoryStore 缓存路径继续使用相同 DataFrame/DataBatch，Linux 区分大小写的 include 使用 data。
