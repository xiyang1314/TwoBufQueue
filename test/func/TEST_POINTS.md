# 功能测试点（先于用例代码制定）

目标是建立可审计的功能回归门槛，不将“测试全部通过”等同于生产认证。接口契约来自当前头文件；不把未声明的并发用法当成有效用法。

|测试点|风险|判定依据|
|---|---|---|
|W1–W4 写入|越界、错误前缀、半消息发布、尾部丢失|独立字节模型、游标、结束后行为|
|R1–R3 读取|重复/漏读、拒收推进、取消损坏、无效注册|完整消息序列、精确错误枚举、源池计数|
|S1–S2 大内存及QueueReader|部分提交错误、队列满覆盖、来源/时间丢失|processed连续前缀、独立输入副本、元数据与统计|
|P1–P4 内存池|位图边界、错误对齐、所有权重复释放|三种策略相同契约、跨代复用、地址唯一性|
|C1–C2 并发|可见性、回收竞争、死锁|barrier同步、每生产者序号、全字节校验、进程超时|
|M1 状态机|组合操作的隐蔽交接错误|固定种子、成功写入参考模型、可复现操作序列|
|D1 违规操作|错误被吞或误诊断|独立子进程+精确原因+专用退出码|
|T1 模板约束|非法API意外可编译|合法对照+编译失败原因核验|
|U1 事件|丢通知、重复通知、不能取消|有界等待、信号语义|

范围：从write到直接回调/大内存队列回调；DataFrame/Slice生命周期；单分配单释放、单分配多释放、多分配多释放。单writer对象禁止多线程同时write，单slice禁止并发release，注册/销毁必须遵守静止期；这些未定义用法不拿压力测试“证明安全”。

已知语义：force扫描仅绕过时间门槛，活动块增长仍需下一轮稳定观察。低频延时问题作为行为记录，不在功能测试中暗改逻辑。回调false须保留完整批次，不能消费部分后false。

方法：不使用会被NDEBUG消除的assert；每个ID独立CTest，失败输出表达式和位置；线程中收集失败，join后报告；无无限循环；随机种子固定；死亡测试必须匹配错误原因，任意崩溃不能蒙混通过；编译失败用合法对照排除环境故障。

验收：用例清单与可执行注册表一一对应；Debug/Release通过；至少Windows GCC/MSVC及Linux GCC中可用环境验证；Linux ASan/UBSan验证；并发用例重复运行。实际覆盖及不可用项记录在RESULTS.md，未执行项不得标为通过。

边界：不声称穷尽线程交错、ARM内存序、OOM每个分配点、进程异常断电或硬实时；这些需要独立的故障注入/架构环境。当前套件不调用无效地址制造UB，不通过放宽断言掩盖库缺陷。发现行为不符时保留失败证据并区分测试错误和实现错误。

补充测试点：W5写端Drop/Block超时/唤醒恢复，R4快速停止及超时后的重启，P5三策略宽松释放不改变状态，D2内部严格释放诊断，S3队列读取器构造校验。先补用例，再实现对应代码。

补充测试点：M2 物理块仅由 Free/Writing/WriteFinished 表示生命周期。三种策略通过统一 to_write_finished 入口完成；Writing 时即使所有切片已释放也不提前回收，WriteFinished 后由最后释放者回收。覆盖空块、先释放后完成、先完成后释放、跨代复用、重复完成与 Free 状态非法完成；源写入与物理块共用 WriteFinished，源块读完最终尾部后调用 finish_alloc，分配未结束时不回收。

补充测试点：W6 可选长度前缀。覆盖 TIsWriteLen=true/false、TDataLen=uint8/16/32/64、逐条/批量发布、紧密参数布局、换块、拒收重试、直接及大内存回调；以独立编码的完整字节序列核验数据。W7 切片容量按实际前缀计算，覆盖最小消息与默认零下限、超过1024个活动切片并持有到完成后释放。W8 长度类型及算术边界，覆盖窄化前拒绝、负数、size_t加法溢出、无前缀空写入、配置不匹配；失败不得改变游标。R5 去掉写入器基类后，不同模板实例可共用Service/Worker，空指针、重复注册、管理器不匹配继续拒绝。T2 非无符号整数长度类型、类型容量不足及无前缀空模板写入必须产生指定编译诊断。

补充测试点：W9 超时策略由 Writer 持有并校验；自旋和阻塞使用同一个总时限，计时包含两个阶段。覆盖非法与最大合法时限、极大自旋次数、超时后读取和重试、累计及最长等待统计；现有唤醒恢复用例继续验证阻塞期间归还。
